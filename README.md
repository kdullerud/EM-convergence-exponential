# Replication (Chandak and Dullerud, 2026+)
Replications files for simulations in Chandak and Dullerud (2026+).

## Overview
* population_sim.py contains the functions for generating the plots in Section 3 (Figures 1 and 2).
* EM_exponential.py contains the functions for generating the plots in Section 4 that correspond to the balanced case (Figures 3 and 4).
* EM_exp_unbalanced.py contains the functions for generating the plots in Section 4 that correspond to the unbalanced case (Figure 5).
